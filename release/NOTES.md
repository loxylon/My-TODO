# My TODO 1.7.0

**Перед переходом с 1.6.0 сохраните JSON-копию в Настройки → Ваши данные → Экспорт.** Ключ подписи 1.6.0 утрачен, поэтому Android не установит этот APK поверх 1.6.0. Убедитесь, что файл копии сохранён, затем удалите 1.6.0, установите `My-TODO.apk` и восстановите данные через Настройки → Ваши данные → Восстановить. Удаление приложения без копии удалит его локальные данные.

Что изменилось:

- Кнопка возврата в просьбы есть только у дел, изначально созданных как просьбы.
- Общий cooldown для просьб без тега — 2 дня. Просьбы с тегом используют cooldown своей группы; выбор любой просьбы запускает паузу для всего тега.
- Компактнее списки и формы, меньше пояснений на основном экране.
- XP начисляется медленнее; новый ранг отмечается отдельным праздничным экраном.

Поддерживается восстановление JSON-копий версий 1.0.0–1.6.0. Приложение работает офлайн на Android 8.0 и новее, в том числе OnePlus 10T.

Подпись 1.7.0: SHA-256 сертификата `628858f6b91f828f8fe8c7ddd838cc8d7e14b7bf8ecac1a823a872d1361073bc`. Для следующих обновлений без переустановки потребуется этот же ключ подписи.
